# 🚕 Cab Booking System

A responsive **Cab Booking System** developed using **HTML, CSS, and JavaScript** that allows users to book rides by entering pickup and drop locations, selecting cab types, calculating fares, and viewing booking details through a simple and user-friendly interface.

## 🚀 Features

* User cab booking interface
* Passenger information management
* Pickup and drop location input
* Multiple cab type selection
* Automatic fare calculation
* Booking confirmation details
* Responsive design for all devices
* Clean and modern user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚕 How It Works

1. Enter passenger details
2. Provide pickup and drop locations
3. Select preferred cab type
4. Enter travel distance
5. System calculates the estimated fare
6. Booking confirmation is displayed
